# PHYSICS DECODED — Vercel migration

This package was generated from the Blogger Takeout Atom feed for PHYSICS DECODED.

## Deploy
1. Upload this folder to a GitHub repository.
2. In Vercel choose Add New → Project.
3. Import the repository.
4. Framework Preset: Other.
5. Build command: leave blank.
6. Output directory: `./`.
7. Deploy.
8. Add `richeshsharma.com.np` under Vercel Project → Settings → Domains and follow the DNS records Vercel gives you.
